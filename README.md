# Pickraft Template Admin

GitHub Pages 前端，账号校验在 Pickraft API 服务端完成。

API 环境变量：

- `PICKRAFT_ADMIN_PORTAL_USERNAME`
- `PICKRAFT_ADMIN_PORTAL_PASSWORD`
- `PICKRAFT_ADMIN_PORTAL_USER_ID`（默认 `admin-portal`，需要加入 `ADMIN_USER_IDS`）
- `PICKRAFT_ADMIN_ORIGIN=https://merrier.wang`

密码不要写入此仓库或 GitHub Pages 构建产物。
